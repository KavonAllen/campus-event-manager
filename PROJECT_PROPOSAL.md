# Campus Event Manager API and Admin Interface – Project Proposal
# GitHub Repository Link - https://github.com/KavonAllen/campus-event-manager.git 
The purpose of the Campus Event Manager application is to provide a centralized system for managing campus events. Colleges and universities regularly organize activities such as student orientations, club meetings, workshops, and other campus gatherings. Keeping track of these events can become difficult when information is spread across different platforms. This application will help simplify that process by providing a backend system that stores event information and allows authorized users to manage it through an administrative interface.

The primary users of the system will be college administrators, faculty members, and other staff responsible for organizing campus events. Students may also benefit from the application by having access to accurate and updated event information. Administrators will be responsible for creating events, updating existing information, viewing scheduled events, and removing events that are no longer needed.

The main features I plan to develop include the ability to create, retrieve, update, and delete events. Each event will contain important information such as its title, description, date, time, location, and category. I also plan to include basic data validation to help prevent incomplete or incorrect information from being submitted. As the project develops, I would like to implement an administrative interface that makes it easier to interact with the event data without having to send API requests manually. Additional features may include searching and filtering events based on their dates or categories, depending on the amount of time available.

For development, I plan to use Node.js as the JavaScript runtime and Express.js to build the backend server and API routes. Visual Studio Code will be my primary code editor, while Git and GitHub will be used for version control and maintaining the project repository. I will use Postman to test API endpoints and verify that requests and responses work correctly. MongoDB Atlas will serve as the database for storing event information.

My goal is to build a functional and organized application while improving my understanding of backend development, database integration, and API design. I will develop the project in stages, beginning with a basic Express server before gradually introducing database operations and additional functionality. This approach will help keep the project within a realistic scope while allowing me to build upon each stage as the course progresses.
